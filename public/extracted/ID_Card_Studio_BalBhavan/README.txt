ID CARD STUDIO - Bal Bhavan International School
================================================

1_Printed_Cards/
  Bal_Bhavan_International_School_A4_Sheets.pdf  -> print this. 5 students per A4, front | back.
  ID_Cards/001_..., 002_...                        -> one PDF per student, in serial order.
  NOTE: 001 and 002 are the same student (Serial 7690) entered twice in the Excel
        with slightly different addresses. Check which address is correct; print only one.

2_Software/
  id-card-studio.html  -> double-click to open in Chrome or Edge. Needs internet (loads fonts and libraries).
     1. Import students (.xlsx)   photos must be placed inside the cells
     2. Student tab: edit details / replace photos per card
     3. Design tab: move/resize fields, upload a school's front/back background, save the design
     4. Export tab: ZIP of A4 sheets + single-card PDFs
  backgrounds/  -> blank Bal Bhavan front/back rebuilt from the sample sheet (low resolution).
                   For final print, export blanks from the PSD at 1063 x 685 px and upload them in the Design tab.

Card size: 90 x 58 mm, 300 dpi. Test-print one sheet first: top/bottom margin is only ~1.5 mm.
